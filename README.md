# digitalEVO — Website Starter

Static, Vercel-ready website for digitalEVO.

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy to Vercel
Import this folder/repository into Vercel. No build command is required because this is a static site.

## Included
- digitalEVO logo
- 9 product packages and provided promotional images
- responsive homepage
- product catalog
- checkout modal
- WhatsApp order handoff
- FAQ and contact sections
- payment integration intentionally left for a later Midtrans step
